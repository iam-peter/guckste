Guckste

A screenshot and screen recording tool in the tray: pick a region, draw on it, copy, save or record it. Its editor combines screenshots, enlarges them pixel for pixel and counts the pixels between two edges.

Download Nightly Source on GitHub

What it does

  • Click the tray icon or bind guckste gui to Print: the screens freeze, then pick a region, a window, a screen, all screens, or last time’s region again.
  • Draw on it right there: pen, lines, arrows, rectangles, ellipses, marker, text, pixelate and numbered markers. Enter copies, Ctrl+S saves, E opens the editor, and a timer catches menus and tooltips.
  • The editor zooms up to 3200 % with every pixel a crisp block and a grid between them, and measure marks count the pixels between two edges.
  • Combine several screenshots and images into one picture. A layer panel lists every mark, and each stays editable: drag a line’s ends or a box’s corners, retype a text where it is.
  • Rulers and guides as in GIMP, with marks snapping to the guides and the guides drawn into the export when you want them.
  • Record a region to a video, with the pointer and the keys pressed if you like, then trim it and draw on it before saving. Qt’s own FFmpeg does the encoding; nothing to install.
  • Keep lossless stills while recording, with a button, a key, before and after every click, or whenever the screen settles after a change, and open them from the timeline as screenshots.

Debian and Ubuntu

The APT repository brings Guckste with its own Qt, for Ubuntu 22.04, Debian 12 and newer.

sudo curl -fsSLo /usr/share/keyrings/guckste-archive-keyring.asc https://iam-peter.github.io/guckste/key.asc
echo "deb [signed-by=/usr/share/keyrings/guckste-archive-keyring.asc] https://iam-peter.github.io/guckste/apt stable main" | sudo tee /etc/apt/sources.list.d/guckste.list
sudo apt update && sudo apt install guckste

The repository is signed with the key 7F3A 61EC A86E 691F 1107 E6FF 4E1C ECA0 0A6F DF42.

Other systems

Each release has an AppImage for any Linux, a zip for Windows and a disk image for macOS. The macOS app isn't signed: open it with a right click and Open the first time, and allow it to record the screen when macOS asks.
